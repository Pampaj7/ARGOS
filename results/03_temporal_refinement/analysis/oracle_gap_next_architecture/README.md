# Oracle-Gap Audit (pre-architecture)

Empirical decomposition of the ~80% unrecovered oracle gap on the 502 selected frames,
plus support/sign/magnitude failure analysis of EGBM-v1/v2/v3(window) and counterfactual
gains from fixing each failure class in isolation. See `oracle_gap_decomposition.json`
for headline numbers and `diagnostics/` for plots. Produced by
`scripts/temporal_refinement/eval_scripts/audit_oracle_gap_next_architecture.py`.

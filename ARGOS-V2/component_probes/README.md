# ARGOS v2 Component Probes

Small deterministic probes over validated SCARED-C cache entries. The scripts use cloned external implementations where executable, and mark dependency-coupled pieces as reference-only instead of substituting unrelated components.

Run:

```bash
.miniconda/envs/argos/bin/python3 ARGOS-V2/component_probes/run_component_probes.py --with-flow --flow-models SEA-RAFT RAFT
```
